Polskie Dyktowanie dla NVDA 2.9.3

Autor Polskiego Dyktanda: Madridista/Realista. Informacja o autorze znajduje się również w ustawieniach dodatku na karcie „Ogólne”.

Alt+Q w polu edycji uruchamia wybrany tryb; poza polem otwiera ustawienia. W trybach dyktowania, czatu i tłumaczenia naciśnij ponownie Alt+Q, aby zakończyć nagrywanie. Drugi skrót uruchamia analizę wybraną w zakładce „Obraz”. Alt+Shift+Q uruchamia tryb wybrany w zakładce „Obraz”. Skróty Ctrl+Alt+Shift+F1–F6 bezpośrednio uruchamiają kolejno opis obrazu z pliku, obrazu pod fokusem NVDA, całego ekranu, kolorów, wideo z pliku i wideo z ekranu. Skróty są zmienialne w zakładce „Skróty”; dla opisu pliku dodatek otworzy wybór załącznika, jeśli nie ma zapamiętanego pliku tego rodzaju.

Tryby

  • Dyktowanie z korektą, interpunkcją, nazwami, akapitami, emoji w serdecznych lub emocjonalnych wypowiedziach i słownikiem.
  • Inteligentny czat z historią sześciu ostatnich wymian.
  • Tłumaczenie nagranej wypowiedzi na wybrany język.
  • Synteza mowy zaznaczonego tekstu przez silnik wybrany na karcie „Ogólne”: Gemini, Grok/xAI lub OpenAI API.
  • Opis obrazu z pliku lub fokusu NVDA, całego ekranu i kolorów oraz wideo z załącznika lub ekranu.
  • Po opisie otwiera się okno „Zapisz jako”. Opis można zapisać jako czytelny plik TXT w UTF-8 z polskimi znakami; nie jest automatycznie kopiowany do schowka.
  • Gemini, Grok/xAI i OpenAI API, test połączenia API, pobieranie modeli, odczyt i kopiowanie ostatniego wyniku oraz opcjonalne Windows Voice Typing.
  • OpenAI API obsługuje transkrypcję dyktowania oraz analizę obrazu, ekranu i wideo.
  • Modele tekstowe i wizualne wybiera się osobno. Model i przycisk pobierania na karcie „Obraz” zmieniają się wraz z aktywnym dostawcą. Transkrypcja audio OpenAI korzysta z gpt-transcribe.
  • Sygnały dźwiękowe dla ustawień oraz początku i końca nagrywania.

Tekst i języki

Ustawienia postępowania z wulgaryzmami, ochrony przed mową z tła i separatora wstawianego przed nowym tekstem są opisane nazwanymi grupami wyboru. Słownik zamian jest opcjonalny: wpisz jedną regułę na wiersz w formacie błędna forma => poprawna forma, aby poprawiać rozpoznane nazwy własne i terminy. Puste pole wyłącza słownik.

Obraz

Wybierz rodzaj analizy, a zdjęcie lub wideo dodaj przyciskiem „Przeglądaj” przy polu „Załącz zdjęcie lub wideo”. Typ pliku ustawia odpowiedni tryb. Obrazy PNG, JPG i WebP mogą mieć do 10 MB. Film jest wysyłany jako równomiernie wybrane klatki bez dźwięku i wymaga FFmpeg oraz FFprobe dostępnych w PATH. Obraz z fokusu używa grafiki wskazanej przez NVDA; opis ekranu analizuje pulpit.

Pliki FFmpeg dla Windows są dostępne na stronie pobierania FFmpeg.

Synteza mowy

Synteza mowy ma osobną kartę, ale automatycznie korzysta z dostawcy i klucza API wybranego na karcie „Ogólne”. Zmiana dostawcy przełącza także ustawienia TTS. Listę modeli Gemini lub OpenAI TTS można pobrać na tej karcie; xAI samo dobiera model TTS, a użytkownik wybiera głos. OpenAI API używa modelu gpt-4o-mini-tts (dłuższy tekst jest dzielony na fragmenty po maksymalnie 4096 znaków); OpenAI zapowiada jego wycofanie 6 stycznia 2027 r.

Konfiguracja i prywatność

Na karcie „Ogólne” wybierz dostawcę Gemini / Google, Grok / xAI albo OpenAI API. Pole klucza API poniżej dotyczy aktualnie wybranego dostawcy; klucze są przechowywane osobno. Dostawca z tej karty służy do tekstu, obrazu i wideo. Syntezę mowy konfiguruje się osobno na karcie „Synteza mowy”, gdzie dostępność Gemini, Grok/xAI lub OpenAI API zależy od wybranego dostawcy i przypisanego mu klucza. Ustawienia modeli znajdują się na kartach poszczególnych dostawców. Użyj przycisku pobierania modeli, a następnie wybierz model z listy. Model tekstowy wybiera się na karcie aktywnego dostawcy. Model wizualny i przycisk pobierania na karcie „Obraz” zmieniają się wraz z aktywnym dostawcą. Transkrypcja audio OpenAI używa gpt-transcribe. Zapisany klucz jest pokazany jako zamaskowany; wpisanie nowej wartości na karcie „Ogólne” go zmieni. Klucz jest chroniony Windows DPAPI. Nagranie jest przetwarzane w pamięci i wysyłane przez HTTPS do dostawcy. Załączniki obrazów i wybrane klatki filmu są wysyłane do dostawcy. Opis ekranu i kolorów wysyła cały pulpit, a wideo z ekranu kolejne zrzuty. Wynik TTS jest tymczasowo zapisywany w pliku systemowym tylko na czas odtwarzania. Klucz OpenAI API i użycie API są rozliczane oddzielnie od subskrypcji ChatGPT. TTS używa klucza aktywnego dostawcy.

Skróty można zmienić w zakładce „Skróty” lub w NVDA > Ustawienia > Zdarzenia wejściowe. Enter po wklejeniu może wysłać formularz. Minimalna wymagana wersja NVDA to 2024.1. Użytkownik potwierdził sprawdzenie paczki 2.9.3 w NVDA 2026.1.
