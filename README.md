# Polish Dictation for NVDA

An NVDA add-on for speech dictation, translation, text-to-speech, and AI descriptions of images, the screen, colors, and video. Supported providers: Google Gemini, xAI Grok, and OpenAI API.

## Key features

- Dictation with punctuation and configurable cleanup, profanity handling, dictionary substitutions, and optional emoji.
- Chat with recent conversation context and speech translation.
- Text-to-speech using the selected supported provider.
- Image, screen, color, and video analysis with dedicated keyboard shortcuts.
- Visual descriptions are offered in a Save As dialog and saved as UTF-8 text with Polish characters.
- Provider/model selection and API connectivity checks.

See the Polish user guide in `readme.html` and `README_PL.txt` for setup, shortcuts, API keys, and media requirements. Video file analysis requires FFmpeg and FFprobe.
